# Variante A — Excel/CSV -> Website (ohne Backend)

## Workflow (super einfach)
1. Datei `export.csv` in Excel öffnen.
2. Termine bearbeiten oder neue Zeilen hinzufügen.
3. Als CSV (UTF-8) speichern.
4. Website neu laden — fertig.

Die Website liest automatisch `export.csv` und zeigt die Events an.
